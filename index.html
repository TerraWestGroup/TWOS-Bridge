Evidence Confidence & Corroboration

TWOS now separates a data point from a management conclusion. Multiple independent sources can strengthen a conclusion without creating extra measures on the Operating Board.

Confidence Evidence state TWOS behaviour
High Current primary evidence corroborated by an independent source, or a single authoritative source with a stable definition May diagnose and assign within established authority
Medium Current evidence establishes the exception but cause is not sufficiently corroborated Seek context before attributing cause or assigning corrective action
Low Stale, incomplete, conflicting or definition-uncertain evidence Investigate only; do not blame, assign or escalate as a confirmed constraint

Evidence promotion gate

Before a number becomes a Bridge management measure, TWOS asks four questions: Is the source real? Is the definition understood? Is it current enough for the decision? Does it change management action?

If the answer to the last question is no, the evidence stays underneath Bridge. This is how additional MechanicDesk reports, Xero detail and Worldline settlements can improve diagnosis without creating dashboard clutter.

TWOS Agent Operating Loop

The hand-off contract for TWOS Agent v0.1. The agent may do the work underneath Bridge; authority and evidence rules determine when Lindsay becomes involved.

Agent modeObserve + Recommend Initial trust stage
Auto-assignOff Until judgement is validated
Evidence gateRequired No unsupported diagnosis
OM boundaryProtected Authority / judgement escalates
Stage Agent responsibility Required gate Bridge outcome
1 · Observe Ingest available MechanicDesk, Xero/dataSights, Outlook and other evidence. Source + timestamp + definition known Evidence retained underneath
2 · Detect Compare position, trajectory and approved standards. Material exception, not noise Exception candidate
3 · Diagnose Trace the likely constraint across Divisions and corroborate independent sources. Confidence assessed Likely constraint + evidence
4 · Context Seek relevant human context when evidence cannot reliably establish cause. No premature blame Diagnosis revised or confirmed
5 · Recommend Propose a specific, measurable, owned and time-bound corrective action. Within current evidence Recommendation / approval request
6 · Act After trust validation, assign routine actions inside delegated authority. Authority + confidence + policy Leader action / OM escalation
7 · Verify Check whether the intended operating result actually changed. Completion is not success Close, continue or escalate case
8 · Learn Recognise recurrence and distinguish one-off exceptions from systemic constraints. Case history preserved Systemic review when warranted

Agent v0.1 authority

May: read evidence, classify it, calculate supported measures, detect exceptions, trace constraints, prepare context questions, create case recommendations and monitor outcomes.

Must not yet: autonomously assign corrective actions, make owner-reserved decisions, alter approved standards, invent missing evidence or close a case merely because a task was completed.

Promotion path: Observe + Recommend → Context + Recommend → Routine Assign + Track → broader delegated autonomy only after its judgement is demonstrated against real TerraWest cases.
